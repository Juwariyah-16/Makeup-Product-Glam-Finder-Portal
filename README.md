# Makeup-Product-Glam-Finder-Portal
A Python-based Makeup Product Finder Portal that allows users to explore, search, filter, and manage makeup products according to category, brand, skin type, and budget. Developed using Python and JSON.
## Glam Finder – Makeup Product Finder Portal

## 1. Introduction
Glam Finder is a Python-based Makeup Product Finder Portal designed to help users explore, search, and manage different makeup products.

Users can find makeup products according to their category, brand, skin type, and budget.

## 2. Project Objectives
- To make makeup product searching easier.
- To help users find products within their budget.
- To organize makeup products in one database.
- To provide a simple and interactive user experience.

## 3. Features
- **User Login:** Allows users to access the portal.
- **View Products:** Displays all available makeup products.
- **Search Products:** Searches products by name.
- **Category Filter:** Filters products by makeup category.
- **Budget Filter:** Finds products within a selected budget.
- **Skin Type Filter:** Displays products according to skin type.
- **Add Products:** Allows users to add new makeup products.
- **Product Report:** Generates a summary of available products.

## 4. Technologies Used
- Python
- Jupyter Notebook
- JSON

## 5. Python Concepts Used
- Variables and data types
- Lists and dictionaries
- Functions
- For loops and while loops
- Conditional statements
- File handling
- Exception handling

## 6. Database
The project uses a JSON file named `products.json` to store makeup product information, including product name, brand, category, skin type, and price.

## 7. How to Run the Project
1. Download the project files.
2. Open `Glam_Finder.ipynb` in Jupyter Notebook.
3. Run all cells in order.
4. Enter the login credentials when prompted.
5. Select an option from the main menu.
